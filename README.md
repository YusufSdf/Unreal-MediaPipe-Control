# Unreal Engine 5 - Real-Time Hand Tracking Control (MediaPipe Tasks + C++)

A high-performance, low-latency bridge between Python MediaPipe Tasks API and Unreal Engine 5 using custom C++ UDP socket communication.

## Demo

https://github.com/user-attachments/assets/fa172b1b-cb8a-430b-84ef-6dad03a38566

## Tech Stack
* **Computer Vision:** Python, OpenCV, MediaPipe Tasks API
* **Engine:** Unreal Engine 5.7 (Native C++)
* **Networking:** Non-blocking UDP Socket (Localhost:5005), JSON Serialization
